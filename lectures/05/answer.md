## 宿題

### 取り組んだレベル

**実装。** ベクトル検索に使う埋め込みモデルを `gemini-embedding-001`（768次元）から `intfloat/multilingual-e5-small`（E5、384次元）に替え、検索順位と回答の違いを調べた。

### やったこと

`app/retrieval.py` で検索用の索引と埋め込み関数を切り替えられるようにした。`scripts/compare_embeddings.py` では配布DBをコピーし、第1〜3回の講義資料214ページについて、本文と引用情報を残してベクトルをE5で作り直した。実験用DBは `AIE_RAG_DB` で別に指定する。

両モデルとも1ページを1チャンクとして、同じコサイン距離で上位5件を取得した。E5では文書に `passage:`、検索語に `query:` を付けた。回答モデルは `gemini-3.5-flash-lite`、検索語は `LoRA QLoRA 違い` にそろえ、ツール説明と回答指示も統一した。 [E5のモデルカード](https://huggingface.co/intfloat/multilingual-e5-small)

### 役立った点と残る課題

LoRAの質問でE5を使うと、原理を説明するp.51が2位から3位に下がり、演習手順のp.61が5位から2位に上がった。上位2件だけを渡すとE5ではp.51が外れる。今回は上位5件を渡したため、どちらもp.51を引用できた。

「第3回の例では、コンパクションとセッションをまたぐメモリはどう違いますか。日々のメモはすべて長期メモリに入りますか」でも検索順位を比べた。基準を満たしたメモだけを残すと説明するp.40はGeminiで4位、E5で1位だった。Geminiで1位のp.65は前半に答えるページだった。上位5件には両方ともp.13・39・40が入り、上位2件でp.39とp.40がそろったのはE5だった。E5の512トークン上限で切り詰められた2ページは、今回確認した上位5件には入っていない。

### 気づき・疑問

11月22日には同じ11種類の検索文をGeminiとE5で試し、どの語や条件で順位が動くかを調べた。

- **LoRAでは「固定」が手がかりになった。** 短い検索語では、Geminiでp.51の類似度がp.61を0.0785上回った。E5ではp.61がp.51を0.0008上回り、ほぼ同点だった。E5の検索語に「固定」を足すとp.51が2位に上がり、「学習」だけを足すと3位のままだった。「固定」で順位が入れ替わった主な理由は、演習ページの類似度が約0.0067下がったことだった。元の質問文をそのまま検索すると、両方ともp.52・51が上位2件に入った。p.61の「QLoRA」を「この手法」に替えてそのページだけ埋め込み直すと、Geminiで5位から57位、E5で2位から11位に下がった。両モデルとも演習ページに出てくる手法名を手がかりにしていたと考えられる。
- **長期メモリでは、問いを分けると結果がそろった。** 「日々のメモはすべて長期メモリに入りますか」だけを入れると、両方ともp.40が1位になった。元の質問に戻し、p.65の「コンパクション」を「履歴の圧縮」に替えると、Geminiではp.65が1位から3位に下がった。p.40は4位のままだった。用語の一致はp.65の順位に関係していたが、後半の根拠が下位に来た理由までは説明できない。取得件数を絞るなら、問いを一つずつ検索する方法も試したい。

Geminiで質問と全214ページのベクトルを先頭384成分に絞っても、LoRAの上位2件は変わらなかった。長期メモリでは1位がp.65からp.39に変わったが、p.40は4位のままだった。質問側の設定をGeminiで `RETRIEVAL_QUERY` から `QUESTION_ANSWERING` に替え、E5で `query:` を外した場合も、それぞれ上位2件は変わらなかった。両モデルは異なるデータと手順で学習しているが、どの違いが今回の順位差を生んだかは特定できない。 [Geminiの技術報告](https://arxiv.org/html/2503.07891) · [E5の技術報告](https://arxiv.org/html/2402.05672)

### 再現方法

E5の `model.onnx` と `tokenizer.json` を同じディレクトリに置く。`GEMINI_API_KEY` を設定し、`AIE_RAG_DB` に未作成のパスを指定して実行する。 [ONNXファイルの配布元](https://huggingface.co/intfloat/multilingual-e5-small/tree/main/onnx)

```bash
AIE_RAG_DB=.cache/rag/e5-lora.sqlite3 uv run --frozen \
  --with 'onnxruntime==1.32.0' --with 'tokenizers==0.23.3' --with 'numpy==2.5.5' \
  python -m scripts.compare_embeddings --e5-dir /path/to/e5
```

検索順位だけを比べる場合は、新しい実験用DBのパスを指定し、コマンドに `--search-only '<検索文>'` を付ける。
